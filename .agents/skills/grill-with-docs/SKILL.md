# Grill with Docs

Read [grilling](../grilling/SKILL.md) for the interview and [domain-modeling](../domain-modeling/SKILL.md) for terminology and decisions. Apply both within the user's requested scope. These are local Markdown dependencies; no Skill tool or slash-command support is required.
