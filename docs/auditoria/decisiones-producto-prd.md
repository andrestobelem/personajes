# Decisiones de alcance del integrador para el PRD

14 de octubre de 2026. Estas decisiones las adopta el agente integrador dentro del objetivo de construir el producto completo. **No se atribuyen al usuario** ni a las respuestas del custodio. La columna de requisitos relacionados incluye origen normativo y también fronteras o dependencias; una relación no convierte automáticamente el requisito entero en decisión nueva. Son reglas de alcance/configuración revisables; las elecciones técnicas con costo de reversión se registrarán en specs/ADRs.

| ID | Decisión y motivo | Requisitos relacionados |
|---|---|---|
| DP-01 | Incluir biblioteca navegable de investigación/fuentes en la GUI, además de expedientes, para preparar la puesta y consultar procedencia sin terminal. La obligación original era guardar documentos; esta navegación es alcance añadido. No se entrega el corpus al actor. | CAT-09, UI-01/09 |
| DP-02 | Incluir capacidades administrativas de preview/selección/guardado de voz y adaptador ElevenLabs de síntesis/reproducción/subtítulos. Cada puesta puede desactivar audio; la capacidad sigue dentro del producto y requiere validación local y live antes del cierre global. Las recetas siguen siendo un requisito separado, sin crear voces automáticamente ni clonar intérpretes. | VOZ-03/04/05/07, P21 |
| DP-03 | Usar corpus y manifiestos versionados. Los 27 expedientes y 16 investigaciones son controles del corte actual, no máximos del catálogo ni obligación de activación. | CAT-01/07/09 |
| DP-04 | Adoptar ICM Memory/SQLite para la integración de memoria persistente estudiada, con separación de corpus por actor y continuidad. La topología física/rutas y relación con el journal se decidirán en specs; no son elección expresa del usuario. | MEM-01, MEM-05/08 |
| DP-05 | Entrada del observador en vista escénica; vista interna mediante elección explícita y aviso de secretos. El operador controla vistas por canal autenticado. La persona observadora no es un rol LLM; inspeccionar no informa al reparto. | UI-05/06, ACT-12 |
| DP-06 | Controles base con reloj congelado en pausa, paso como pulso acotado, detención cancelable/reanudable y cierre terminal con historia conservada. No avance fuera de línea por defecto. Zona horaria/convención se deriva o declara sin inventar el momento ficticio. | TIM-02/03, ESC-01 |
| DP-07 | Incluir navegación por teclado/etiquetas y flujo de import/export versionado con validación y protección de originales. Son decisiones para hacer operable la GUI completa y conservar ICM; se probarán como capacidades, no se anunciarán por tener un documento. | UI-08/10, NFR-02/07 |
| DP-08 | Adoptar como default el límite del protocolo de obra: dos reformulaciones y tres versiones totales por propuesta. Se puede reducir antes de actuar a cero o una reformulación; el techo vigente sigue siendo dos reformulaciones/tres versiones totales. Elevarlo requeriría revisar expresamente protocolo y aceptación, no un argumento del actor; agotar intentos no inventa respuesta ni habilita una versión no revisada. La cifra es elección operativa del integrador, no mandato humano derivable por lógica. | ACT-08, P10 |
| DP-09 | Exigir que la convención de variedad del español quede declarada en la puesta, pudiendo conservar una propuesta editorial identificada hasta elegirla. La propuesta editorial es admisible para actuación textual; antes de solicitar preview/síntesis se confirma la variedad y se comprueba la convención seleccionada en la voz. No se atribuye al usuario una variedad latinoamericana exacta ni se exige que el personaje conozca el idioma de doblaje como lengua diegética. | VOZ-01, P05/P07/P21 |


Las tools ficticias sólo operan sobre el Escenario. Login, memoria, TTS y mantenimiento tienen adaptadores de host separados; una frase del personaje no activa integraciones externas arbitrarias. Las cifras de ritmo no se inventan: la calibración permanece pendiente de escucha.
